# Инструкции для Claude

- Общение с пользователем — на русском, простым языком (пользователь новичок).
- Не использовать платные API без явного разрешения пользователя.
- В задачах по анимациям (2D/3D, Remotion, Three.js, короткие ролики, стили видео)
  использовать скилл `lemo-opuscar` из `.claude/skills/lemo-opuscar/`:
  его стили и техники — источник идей и приёмов для анимаций в этом редакторе.
- 3D-анимации делать ТОЛЬКО стеком Three.js (@react-three/fiber + @remotion/three) + Remotion
  (субтитры, звук, рендер). Перед любой задачей по анимации прочитать `ANIMATION_RULES.md`
  и следовать ему. После каждой правки пользователя дописывать новое правило в этот файл
  и строку в его «Журнал итераций».
