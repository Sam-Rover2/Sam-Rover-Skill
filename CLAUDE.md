# Инструкции для Claude

- Общение с пользователем — на русском, простым языком (пользователь новичок). **Писать всегда подробно:** пошаговые инструкции (куда нажать, какую команду ввести, что должно появиться), объяснять что сделано и зачем.
- Не использовать платные API без явного разрешения пользователя.
- **Любой ролик или анимация — только через скилл `pipeline`** (бриф → персонажи → объекты → локации → расстановка без анимации → анимация частей по 20–30 с → финал), с согласованием после каждого этапа. Весь ролик сразу не делать.
- **Скилл `qa` — всегда:** перед любой работой над анимацией, сценой, персонажем, локацией пройти его чек-лист. Каждую правку пользователя исправить и записать в `qa` (журнал + чек-лист).
- Эталонные ролики и разбор стиля — `references/` (`REFERENCE.md`). Формат по умолчанию — вертикальный 9:16.
- Согласование этапов 1–4 — интерактивный `review/Согласование.html` (`npm run review`), присылать после каждого изменения.
- Модели пользователя (GLB/FBX) — в `public/models/`, подключать через `<Model>` и стилизовать.
- Шаблон проекта ролика с плеером — `film-template/` (Remotion Studio, папки этапов). Новый ролик = копия в `films/<имя>/`.
- 3D-анимации делать стеком Three.js (@react-three/fiber + @remotion/three) + Remotion. Технические правила стиля — `ANIMATION_RULES.md`.
- В задачах по стилям видео можно брать приёмы из скилла `lemo-opuscar`.
