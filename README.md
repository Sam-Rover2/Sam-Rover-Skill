# 🎬 AI Video Editor (MVP)

Веб-редактор видео на **React + TypeScript + Remotion + FFmpeg (WebAssembly)**.
Всё работает прямо в браузере: видео никуда не загружается, платные API не используются.

## Что уже умеет

| Функция | Статус |
|---|---|
| Загрузка MP4 (кнопка или перетаскивание) | ✅ |
| Видеоплеер (Remotion Player) + таймлайн с курсором | ✅ |
| Выбор диапазона «от / до» (вручную или кнопкой «← текущее время») | ✅ |
| Текстовый промпт для каждой правки | ✅ (пока не отправляется в ИИ) |
| Изображения-референсы к правке | ✅ (первое показывается в углу кадра) |
| 2D-анимации поверх видео через Remotion: титр, зум, фигуры | ✅ |
| Предпросмотр в плеере | ✅ |
| Экспорт диапазона в MP4 через FFmpeg | ✅ (без наложенных анимаций) |
| 3D-анимации (Three.js) | ⏳ следующий шаг |
| Экспорт MP4 *с* анимациями | ⏳ нужен Remotion-рендер на сервере |
| ИИ, превращающий промпт в анимацию | ⏳ только с вашего разрешения (обычно это платные API) |

## Как запустить (для новичка)

1. Установите **Node.js 20+** с https://nodejs.org (версия LTS).
2. Откройте терминал в папке проекта и установите зависимости:

```bash
npm install
```

3. Запустите режим разработки:

```bash
npm run dev
```

4. Откройте в браузере адрес из терминала (обычно http://localhost:5173).

Другие команды:

```bash
npm test
```

```bash
npm run build
```

`npm test` запускает тесты, `npm run build` собирает готовый сайт в папку `dist/`.

## Как пользоваться

1. Нажмите **«Загрузить MP4»**.
2. Укажите диапазон «от» и «до» (жёлтая рамка на таймлайне) и нажмите **«+ Добавить правку»**.
3. Справа напишите промпт, выберите эффект, добавьте картинки-референсы — плеер сразу покажет результат.
4. **«Экспорт фрагмента в MP4»** скачает вырезанный кусок видео. При первом экспорте браузер скачает FFmpeg (~30 МБ, бесплатно, с CDN unpkg.com).

## Структура проекта

```
src/
  App.tsx                       главный экран: загрузка, плеер, диапазон, список правок
  components/Timeline.tsx       таймлайн
  components/SegmentEditor.tsx  панель правки (промпт, эффект, референсы)
  remotion/VideoComposition.tsx Remotion-композиция: видео + слои правок
  remotion/Overlay.tsx          программные 2D-анимации
  lib/time.ts                   чистые функции (время, диапазоны, аргументы FFmpeg) + тесты
  lib/ffmpeg.ts                 обрезка видео через ffmpeg.wasm
```

## Деплой

Это статический сайт (папка `dist/`), отдельный сервер не нужен.

- **Netlify**: подключите репозиторий — настройки уже в `netlify.toml`.
- **Vercel**: подключите репозиторий — настройки в `vercel.json`.
- **GitHub Actions** (`.github/workflows/ci.yml`) на каждый push запускает тесты и сборку.
