# Ink Diorama Toon — как делать ролик

Стиль сделан с пользователем по его эталонам (`references/`) на технике стиля Memphis Diorama из библиотеки `lemo-opuscar`. Описание стиля: `ink-toon-test/style/STYLE.md`, решения: `CHANGES.md`. Рабочий пример: `films/hanoi-rats/src/movie/`.

Всегда вместе со скиллами `pipeline` и `qa` (чек-лист QA перед любой работой).

## Что делает стиль узнаваемым

1. **Каждый план — маленькая яркая диорама** под этот кадр (угол комнаты / кусок улицы), а не одна большая локация на весь ролик.
2. **Персонажи крупно** (⅓–½ высоты кадра): белая голова-шар с толстым контуром, тело-пилюля, длинные тонкие ноги и руки, белые кисти.
3. **Чёрный контур на ВСЕХ гранях** — проход `InkPass` (нормали + глубина), толщина от меньшей стороны кадра.
4. **Насыщенный цвет + цветной свет** (день, тёплый офис, бирюзовая канализация, синяя ночь, закат).
5. **Зерно и «печатная» фактура**, тёмная фиолетовая **виньетка**.
6. **Субтитры** по 1–3 слова (Nunito Black, белые, тёмная обводка, чуть ниже центра, лёгкий «поп»).
7. **Широкий объектив близко** к героям, медленный наезд, склейка на фразе диктора.

## Движок (files/hanoi-rats → копировать в новый ролик)

| Файл | Что делает |

## Порядок работы

1. Озвучка `voice.mp3` + `voice.srt` → `src/film/words.ts` (тайминги слов).
2. `TREATMENT.md`: три варианта структуры → выбор. Один план = одна фраза (2–4 с).
3. Для каждой роли в тексте — **свой персонаж** (правительство ≠ чиновник-строитель).
4. План = `Shot` + своя декорация + персонажи + действие **на ключевом слове**.
5. Проверка стоп-кадрами в ОБОИХ форматах: начало/середина/конец каждого плана + моменты действий (`tools/cloud.sh still src/index.ts new-film …` и `new-film-wide`), лист кадров рядом с эталоном.
6. Каждую правку пользователя — в `qa` (журнал + чек-лист).

## Правила (выжимка из QA-035…047)

- Камера: медленный наезд, без облётов/тряски/крена/вспышек; не проходит сквозь предметы; `fit` — ширина, которая обязана влезть (по умолчанию 5.8; крупные планы 2–4.8).
- Склейки чистые: всё на одном `FilmCanvas` — никаких цветных экранов.
- Комнаты закрыты со всех сторон (`Room closed`, потолок): обратный ракурс не видит пустоты. Фон заполнен (5+ предметов, многоэтажные дома).
- Ходьба: `walkTo` — шаги от пройденного пути, остановился — ноги стоят.
- Любая смена позы плавная 0.3–0.5 с (`sm`, `mixV`); колебания медленные. Никаких рывков.
- Руки вне головы и тела; поднятые руки — в стороны. Глаза/очки по поверхности головы.
- Крысы на четырёх лапах; предметы не уходят в пол (ручку лупы — вверх).
- Ролик всегда в двух форматах: 9:16 и 16:9.

## Субтитры — переключатель (всегда)
Композиция ролика получает `schema` (zod) с полем `subtitles: boolean` и `defaultProps={{ subtitles: true }}` — в Remotion Studio справа на панели **Props** появляется галочка; рендер без субтитров: `--props='{"subtitles":false}'`. Пример: `films/income-building/src/building/Film.tsx`.
