# Шаблон ролика (плеер + этапы)

Каждый новый ролик делается по этому шаблону. Работа идёт по этапам, и каждый этап вы смотрите в **плеере** (Remotion Studio).

## Как открыть плеер
1. Один раз установите **Node.js LTS** с https://nodejs.org.
2. Дважды кликните:
   - Windows: `Запустить плеер (Windows).bat`
   - Mac: `Запустить плеер (Mac).command`

   Или в терминале в этой папке:

```bash
npm install
```

```bash
npm run player
```

3. Откроется браузер с плеером. Слева папки этапов:

| Папка | Что смотреть |
|---|---|
| `1-Characters` → `cast` | все персонажи ролика |
| `2-Objects` → `obj-…` | каждый объект (реквизит, транспорт…) |
| `3-Locations` → `loc-…` | каждая локация, камера облетает |
| `4-Staging` → `staging-…` | расстановка без анимации через камеры кадров |
| `5-Parts` → `part01`… | анимированные куски по 20–30 секунд |
| `6-Film` → `film` | весь фильм из согласованных частей (120 FPS) |

4. Нажмите ▶ и смотрите.
   - **Нравится** → нажмите **Render** справа вверху. Готовый MP4 появится в папке `out/`.
   - **Не нравится** → напишите Claude, что поправить. Правка будет записана в скилл QA, и такой ошибки больше не будет.

Рендер финального фильма из терминала:

```bash
npm run render
```

Если появится ошибка WebGL, в PowerShell выполните `$env:REMOTION_GL="swangle"` и запустите рендер снова.

## Согласование в 3D (до анимации)
Откройте **`review/Согласование.html`** двойным кликом (интернет не нужен):
- слева этапы: Персонажи → Объекты → Локации → Расстановка;
- **левая кнопка мыши** поворачивает «голову» камеры, как в игре; **W A S D** — лететь, **Q / E** — вниз и вверх;
- **колесо мыши** — скорость полёта: вверх быстрее, вниз медленнее (от 1 до 40, индикатор внизу), **Shift** — временно ×3;
- в «Расстановке» кнопки 🎥 показывают будущие кадры, «Рамка» — что попадёт в вертикальное видео;
- **📍 Точки**: включите кнопку и кликайте по сцене. Появятся метки 1, 2, 3 с названием объекта; напишите у метки, что сделать (например, «перенести в точку 2»), а метку-цель можно оставить пустой;
- пишите правки в поле внизу, затем «📋 Скопировать все правки» и вставьте в чат;
- когда правки применены, нажмите «🗑 Очистить все правки»: удалятся все заметки во всех этапах.

Пересобрать файл после изменений: `npm run review`.

## Ваши 3D-модели
Положите GLB в `public/models/`. FBX Claude сконвертирует сам.

## Где что лежит
- `src/project.ts` — название, FPS, **персонажи** (этап 1) со статусом «черновик / согласован».
- `src/objects/` — **объекты** (этап 2).
- `src/locations/` — **локации** (этап 3).
- `src/staging/` — **расстановка** и камеры кадров (этап 4).
- `src/parts/` — **анимация частей** (этап 5).
- `src/lib`, `src/rig`, `src/props` — стиль, риг персонажей, готовые объекты.
