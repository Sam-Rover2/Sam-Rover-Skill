# «Красный шарик»: 3D-мультфильм, 40 секунд, 120 FPS

Мультфильм без субтитров: историю рассказывают мимика и движения. Он целиком собран кодом:
- **Three.js** строит 3D-сцены, персонажей и свет;
- **Remotion** отвечает за монтаж, субтитры, звук и сборку MP4.

Платные сервисы не используются, всё работает на вашем компьютере.

## Как отрендерить на своём ПК (Windows / macOS / Linux)

### 1. Один раз: установить Node.js
Скачайте **Node.js LTS** (версия 20 или новее) с https://nodejs.org и установите с настройками по умолчанию.

### 2. Скачать проект
На GitHub откройте ветку `claude/inspiring-pascal-wylpjr` → зелёная кнопка **Code** → **Download ZIP**. Распакуйте архив.

### 3. Открыть терминал в папке `toon-film`
- **Windows:** откройте папку `toon-film` в Проводнике, кликните в адресную строку, наберите `powershell` и нажмите Enter.
- **macOS:** правый клик по папке `toon-film` → «Новый терминал по адресу папки».

### 4. Установить зависимости (один раз, 1–3 минуты)

```bash
npm install
```

### 5. Посмотреть фильм в браузере (по желанию)

```bash
npm run studio
```

Откроется Remotion Studio: там можно листать фильм по кадрам. Чтобы закрыть её, нажмите в терминале `Ctrl+C`.

### 6. Отрендерить финальное видео 1920×1080, 120 FPS

```bash
npm run render
```

Готовый файл появится в `toon-film/out/film.mp4`. Это 4800 кадров. С видеокартой рендер займёт примерно 5–20 минут, без неё дольше.

Быстрая черновая версия в 30 FPS:

```bash
npm run render:preview
```

## Если что-то пошло не так

| Ошибка | Что сделать |
|---|---|
| `Error creating WebGL context` | Видеокарта недоступна браузеру. В PowerShell выполните `$env:REMOTION_GL="swangle"`, затем снова `npm run render`. На macOS/Linux: `REMOTION_GL=swangle npm run render` |
| Рендер тормозит или не хватает памяти | Добавьте ограничение потоков: `npm run render -- --concurrency=2` |
| `npm` не найден | Node.js не установлен или терминал открыт до установки. Перезапустите терминал |

## Как устроен проект

```
src/
  Film.tsx            монтаж: список сцен (секунды), звук, затемнения. Субтитров нет
  Root.tsx            композиции: Film (120 FPS) и FilmPreview (30 FPS)
  cast.ts             внешность персонажей (Макс, Лена, коллеги)
  scenes/S1Market.tsx  1. рынок: Лена покупает шарик, ветер его уносит
  scenes/S2Sky.tsx     2. шарик летит вдоль 5-этажного дома, соседка машет с балкона
  scenes/S3Roof.tsx    3. крыша: Макс поливает цветы и ловит шарик
  scenes/S4Run.tsx     4. Макс бежит по улице (низкая камера показывает высоту домов)
  scenes/S5Fountain.tsx 5. парк у фонтана: грустная Лена, Макс возвращает шарик
  scenes/S6Sunset.tsx  6. финал: уходят на закат, камера поднимается
  props/Big.tsx        здания в реальном масштабе, шарик на нитке, тележка, фонтан
  rig/world.ts         мировая позиция кисти (передача предметов без скачков)
  rig/Limb.tsx        риг рук и ног на кривой Безье: гнутся, концы скруглены
  rig/Character.tsx   параметрический персонаж (лицо, причёски, одежда, позы)
  rig/motion.ts       ходьба, сидение, дыхание
  props/              мебель, город, природа, небо
  lib/                стиль (палитра, линия), материалы, камера, субтитры
tools/make_audio.py   генератор музыки и звуков (python3 + numpy)
public/audio/film.wav готовый звук
```

Все анимации считаются в **секундах**, а не в кадрах. Поэтому один и тот же фильм рендерится и в 30, и в 120 FPS без изменений.

Правила стиля и все правки собраны в `../ANIMATION_RULES.md`.
